## 2026-05-09：确认 post-MVP 路线和朋友试玩后置

## 2026-05-05：血量显示采用主 HUD + 脚下辅助

决策：

- 主血量常驻放在左上 HUD。
- 少侠脚下只显示辅助血条，用于受伤和低血量近场反馈。
- 脚下辅助血条默认隐藏；受伤后显示 2 秒，血量低于 30% 时常驻显示。
- 脚下不显示血量数字。

原因：

- 满屏江湖敌人和招式特效会遮挡少侠脚下区域，脚下血条不能作为唯一血量来源。
- 但受伤时玩家视线通常在少侠附近，脚下短时血条能更快建立“我正在掉血”的反馈。
- 用双层显示可以兼顾可读性和战斗直觉：左上负责稳定读数，脚下负责即时反馈。

## 2026-05-05：细化少侠移动与受伤系统

决策：

- 战后清点负责胜败、存活时间、击杀、等级、铜钱、最好纪录和重开入口。
- `翻阅秘籍` 页面必须默认显示概率、保底、铜钱不足状态、结果卡和重复补偿。
- 音频采用“占位层 -> 生成层 -> 整理层”管线；可以使用本机私有音频 API key 生成素材草案，但 key 不进入仓库、不进入日志、不参与运行时。

原因：

- 用户指出开始、阵亡、结算、音频制作和抽取 UI 仍不够清楚。
- 从第一性原则看，这些页面是单局闭环的入口、失败反馈、奖励兑现和长期目标。如果不在文档中定义，后续实现会出现“能跑但不像完整游戏”的问题。
