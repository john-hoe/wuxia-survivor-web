# 12 Wuxia Style And Level

## 目的

本项目从通用 survivor-like 改为原创武侠风格。

目标不是做严肃大型武侠 RPG，而是做一个轻武侠、强反馈、短局的“江湖割草”Web 游戏。

## 风格定位

一句话：

> 少侠在山道和山寨之间突围，用剑气、掌风、暗器和护体真气抵挡一波波江湖敌人，击败首关头目后获得铜钱和秘籍残页。

关键词：

- 江湖。
- 山道。
- 山寨。
- 少侠。
- 剑气。
- 掌风。
- 暗器。
- 护体真气。
- 铜钱。
- 秘籍残页。

禁止方向：

- 不做修仙飞升。
- 不做大宗门养成。
- 不做满屏仙法光污染。
- 不做复杂剧情和门派政治。
- 不使用真实武侠 IP、角色、门派名或招式名。

## MVP 关卡

MVP 只做 1 个关卡。

暂定名：`青石山道`。

关卡实现级规格见 [18 Stage Qingshi Mountain Road System](18-stage-qingshi-mountain-road-system.md)。

场景目标：

- 6 到 8 分钟单局。
- 山道 + 山寨入口 + 竹林/碎石边界。
- 敌人从四周和山道尽头涌入。
- 第 6 分钟出现首关头目。

不做：

- 第二关。
- 多关卡随机池。
- 大世界选择关卡。
- 复杂剧情过场。

后续关卡只在 MVP 成功后再做。

## 首关敌人

敌人属性、刷怪时间轴、精英和回收规则见 [17 Enemy Wave And Director System](17-enemy-wave-and-director-system.md)。

| 敌人 | 优先级 | 行为 | 作用 |
| --- | --- | --- | --- |
| 山贼喽啰 | P0 | 慢速追击 | 基础怪潮和击杀反馈 |
| 恶犬 | P0 | 快速靠近，血少 | 逼迫走位 |
| 持盾山贼 | P0 | 移速慢、血厚 | 检验持续输出 |
| 木人机关 | P0 精英 | 精英单位，体型大 | 阶段变化和高内力掉落 |
| 黑衣快刀手 | P1 | 中速，接近后伤害较高 | 中后段压力 |

MVP 实现前 3 类普通敌人 + 1 个精英。`黑衣快刀手` 等 MVP 成功后再加入。

## 首关头目

暂定名：`黑风寨主`。

头目实现级规格见 [19 Boss Heifeng Chief System](19-boss-heifeng-chief-system.md)。

头目行为：

- 冲撞斩：短暂停顿后直线冲刺，地面出现红色刀痕预兆。
- 旋风刀：原地蓄力后环形刀气扩散。

头目规则：

- 第 6 分钟出现，MVP 不做击杀数提前触发。
- 攻击前至少 0.5 秒有视觉预兆和声音预警。
- 击败后进入战后清点。

## MVP 招式池

招式数值、释放、冷却和进阶规则见 [16 Skill And Advancement System](16-skill-and-advancement-system.md)。

| 招式 | 优先级 | 行为 | 进阶方向 |
| --- | --- | --- | --- |
| 游龙剑气 | P0 | 自动向最近敌人发出剑气 | 穿透、连发、追踪 |
| 回风飞镖 | P0 | 飞镖环绕少侠 | 更多数量、更大半径 |
| 震山掌 | P0 | 定时释放近身冲击波 | 范围扩大、冷却降低 |
| 毒砂袖箭 | P1 | 自动射出带持续伤害的暗器 | 毒雾扩散、叠毒 |
| 护体真气 | P1 | 周身短距离防护圈 | 减伤、击退、反震 |

MVP 实现顺序：

1. 游龙剑气。
2. 回风飞镖。
3. 震山掌。
4. `毒砂袖箭` 和 `护体真气` 后续补。

## 招式进阶

MVP 进阶示例：

| 基础招式 | 条件 | 进阶 |
| --- | --- | --- |
| 游龙剑气 Lv5 | 剑谱残页 | 游龙归海 |
| 回风飞镖 Lv5 | 暗器囊 | 回风连环 |
| 震山掌 Lv5 | 内劲心法 | 裂石掌风 |

进阶必须肉眼可见：

- 弹体形态变化。
- 范围变化。
- 音效更强。
- 图标边框变化。

## 掉落和结算

铜钱、局外成长、翻阅秘籍和存档见 [20 Copper Meta Scripture System](20-copper-meta-scripture-system.md)。

局内掉落：

- 内力光点：用于本局领悟。
- 铜钱：MVP 不做战斗直接掉落；新增铜钱主要来自战后清点。
- 回血药丸：少量恢复。

结算铜钱建议仍沿用原公式，但显示为铜钱：

```text
铜钱 = floor(存活秒数 / 10) + 击杀数 * 1 + 等级 * 8 + 头目奖励
```

头目奖励建议 `150` 铜钱。

## 秘籍抽取

原“金币抽卡”改为“铜钱抽秘籍”。

规则不变：

- 只消耗铜钱。
- 铜钱不能购买。
- 概率公开。
- 重复奖励转为残页或铜钱返还。
- 每 20 抽至少 1 个稀有或以上。
- 不做限时池、付费池、广告池。

抽取内容建议：

| 奖励类型 | 表现 |
| --- | --- |
| 普通残页 | 通用秘籍残页 |
| 稀有外观 | 服饰、斗笠、剑穗 |
| 稀有被动碎片 | 轻功、体魄、拾取范围 |
| 史诗收藏品 | 称号、特殊招式皮肤、入场特效 |

## 美术风格补充

P0 视觉基线在 `docs/10-art-animation-vfx.md` 基础上改为武侠语义：

- 少侠：青绿/白色高亮少侠剪影。
- 普通敌人：山贼暖色、黑衣人暗紫灰。
- 内力：蓝青色内力光点。
- 铜钱：金黄铜钱，不与危险黄色混淆。
- 友方技能：青白剑气、淡绿掌风、银色暗器。
- 危险范围：红橙刀痕或冲击范围。
- 关卡：低噪声山道、竹林边界、山寨木桩。

风险：

- 水墨黑白灰过多会降低可读性。
- 特效太仙侠会偏离武侠。
- 竹林/山道纹理过密会抢掉落物。

## HUD 文案

原则：MVP 屏幕上每个概念只允许一个正式叫法。不要给玩家同时看到“等级/境界”“金币/铜钱”“升级/领悟”这类混称。

正式显示文案：

| 游戏概念 | 屏幕固定文案 | 使用位置 | 示例 |
| --- | --- | --- | --- |
| 生命值 | 血量 | 左上 HUD、低血量提示 | `血量 68/100` |
| 角色等级 | 等级 | 左上状态、战后清点 | `等级 3` |
| 经验条 / XP | 内力 | 顶部进度条、领悟进度 | `内力 42/100` |
| 局外货币 | 铜钱 | 战后清点、翻阅秘籍页 | `铜钱 +120` |
| 已获得技能/武器 | 招式 | 底部招式槽、领悟卡 | `招式 2/6` |
| 升级选择 | 领悟 | 三选一弹窗标题 | `领悟` |
| 招式进化 | 进阶 | 满足条件后的强反馈提示 | `游龙剑气进阶` |
| 开始按钮 | 开始闯荡 | 主菜单主按钮 | `开始闯荡` |
| 阵亡过渡 | 力竭倒地 | 死亡后短过渡 | `力竭倒地` |
| 单局结算 | 战后清点 | 结算页标题 | `战后清点` |
| 抽取入口 | 翻阅秘籍 | 局外入口、抽取页标题 | `翻阅秘籍` |
| 单抽按钮 | 翻阅一次 | 翻阅秘籍页按钮 | `翻阅一次 300 铜钱` |
| 奖励碎片 | 秘籍残页 | 翻阅秘籍结果、收藏页 | `获得秘籍残页 x3` |

禁止在 MVP 的玩家可见 UI 中混用：

- `境界`：暂不用于 HUD，避免玩家以为存在修仙境界突破系统。
- `生命` / `HP`：战斗 HUD 统一显示为 `血量`。
- `经验` / `XP`：统一显示为 `内力`。
- `金币`：统一显示为 `铜钱`。
- `武器`：统一显示为 `招式`。
- `升级`：统一显示为 `领悟`。
- `进化`：统一显示为 `进阶`。
- `抽卡` / `Gacha`：统一显示为 `翻阅秘籍`。

实现时可以保留英文代码名，例如 `level`、`xp`、`gacha`，但屏幕显示文案必须按上表输出。

## 后续关卡池

只在 MVP 成功后考虑：

- 竹林夜路。
- 破庙围攻。
- 镖局门前。
- 河岸码头。
- 古道客栈。

每个新关卡必须至少带来一种差异：

- 新敌人行为。
- 新头目机制。
- 新地形风险。
- 新招式或新掉落。

不允许只换背景图就叫新关卡。

## 验收

MVP 武侠风格通过线：

- 3 秒内能看出这是武侠江湖，而不是科幻、仙侠或现代枪战。
- 首关只有 `青石山道` 一个关卡入口。
- 少侠、敌人、内力光点、铜钱、危险刀痕可读。
- 至少 3 个招式名称和表现符合武侠语义。
- 抽取页面使用“铜钱”和“秘籍/残页”语义，无充值入口。
- 后续关卡只出现在文档规划，不进入 MVP 实现。
