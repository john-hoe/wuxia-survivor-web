# 20 Copper Meta Scripture System

## 目的

铜钱、局外成长和翻阅秘籍负责单局之后的长期目标。

第一性原则：

- 失败也有积累，但不能让局外成长替代局内走位和领悟。
- 随机奖励可以有期待感，但必须只消耗游玩铜钱。
- 不允许任何商城、充值、广告、体力、限时池或付费保底。

## 范围

P0 必做：

- 战后铜钱结算。
- 3 个局外成长项。
- 1 个基础翻阅秘籍池。
- 概率公开、重复补偿、20 抽保底。
- `localStorage` 存档。

非目标：

- 不做付费货币。
- 不做账号系统。
- 不做每日任务压力。
- 不做联网排行榜。

## 铜钱来源

MVP 新增铜钱只允许来自战后清点结算：

- 单局存活时间。
- 击杀数。
- 本局等级。
- 击败头目奖励。

翻阅秘籍重复奖励可以返还少量铜钱，但它属于已消耗铜钱的补偿记录，不属于战斗掉落或外部新增来源。

禁止来源：

- 充值。
- 广告。
- 每日登录。
- 外部兑换码。
- 付费礼包。

## 战后结算公式

```text
base = floor(survivalSeconds / 10) + kills * 1 + level * 8
bossBonus = bossDefeated ? 150 : 0
copperEarned = floor((base + bossBonus) * difficultyMultiplier)
```

MVP `difficultyMultiplier = 1.0`。

目标收益：

| 情况 | 目标铜钱 |
| --- | ---: |
| 2-3 分钟早期失败 | 60-120 |
| 4-5 分钟中段失败 | 150-260 |
| 6-8 分钟击败头目 | 350-500 |

结算页显示：

- `战后清点`
- 存活时间
- 击杀
- 等级
- 铜钱 +N
- 是否击败 `黑风寨主`
- `再来一局`
- `返回主菜单`
- `翻阅秘籍`

## 局外成长项

| 名称 | 存档 key | 每级效果 | 最高等级 | 成本 |
| --- | --- | ---: | ---: | --- |
| 体魄训练 | `max_hp` | 最大血量 +5% | 5 | 120/220/360/520/720 |
| 轻功步法 | `move_speed` | 移动速度 +3% | 5 | 120/220/360/520/720 |
| 磁石锦囊 | `pickup_radius` | 拾取半径 +5% | 5 | 100/200/320/480/680 |

强度边界：

- 最大血量总加成最多 25%。
- 移动速度总加成最多 15%。
- 拾取半径总加成最多 25%。
- 不允许出现伤害翻倍、开局满级、付费复活等破坏本局构筑的成长。

当前工程实现：

- `ScriptureScene` 的 `局外成长` 页展示并购买 3 个成长项，购买只消耗存档铜钱并写入 `localStorage`。
- 下一局开始时读取 `metaUpgrades`：体魄训练影响初始最大血量，轻功步法影响初始移动速度，磁石锦囊影响初始拾取半径。
- 页面使用 `SW-ART-014` 13 个最终 alpha 图标中的 3 个局外成长图标；桌面和移动横屏截图证据见 `evidence/2026-05-07-sw-art-014-import/`。

## 翻阅秘籍

入口文案：`翻阅秘籍`。

按钮文案：

- `翻阅一次 300 铜钱`
- `翻阅十次 3000 铜钱`

概率必须在页面中明示：

| 稀有度 | 概率 | 内容 |
| --- | ---: | --- |
| common | 65% | 普通秘籍残页、少量铜钱返还 |
| rare | 25% | 外观残页、轻成长碎片 |
| elite | 9% | 稀有心法碎片 |
| epic | 1% | 称号、招式皮肤、入场特效 |

保底：

- 每 20 抽至少 1 个 `rare` 或以上。
- 抽到 `rare` 或以上后，保底计数清零。
- 保底不需要付费触发。

重复补偿：

| 重复稀有度 | 补偿 |
| --- | --- |
| common | 20-40 铜钱或普通残页 |
| rare | 1 个稀有残页 |
| elite | 1 个稀有心法碎片 |
| epic | 3 个史诗碎片 |

MVP 实现口径：

- `fragments` 是可堆叠资源，不按“已拥有”判定重复；抽到同类残页会继续累加。
- `skins` 和 `titles` 是收藏项，已拥有时判定为重复，并转为残页或铜钱补偿。
- `铜钱返还` 属于普通奖励项或重复补偿项，不能作为外部新增铜钱来源理解。

## 翻阅秘籍 UI

玩家看到的是 `翻阅秘籍`，不是 `抽卡` 或 `Gacha`。

页面布局：

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 顶部 | `翻阅秘籍`、当前铜钱 | 当前铜钱不足时变灰，不变红催促 |
| 概率说明 | common 65%、rare 25%、elite 9%、epic 1%、20 抽保底 | 默认可见，不藏在二级菜单 |
| 操作按钮 | `翻阅一次 300 铜钱`、`翻阅十次 3000 铜钱` | 不足时置灰，提示 `铜钱不足` |
| 结果卡 | 奖励名、稀有度、数量、是否重复 | 64x64 图标仍能识别 |
| 补偿提示 | 重复转为残页或铜钱返还 | 必须和原奖励同时显示 |

结果流程：

1. 玩家点击翻阅按钮。
2. 系统检查铜钱、保底计数和存档可写状态。
3. 扣除铜钱并生成结果，写入本地存档。
4. 播放 `scripture_reveal_*` 音效和 `vfx_scripture_reveal`。
5. 展示结果卡，稀有及以上卡片停留至少 0.8 秒。
6. 玩家确认后回到翻阅秘籍页面或战后清点页面。

当前工程实现：

- `翻阅一次` 和 `翻阅十次` 已扣除铜钱、生成结果、写入存档并更新保底计数。
- 页面显示 `距保底 N 次`，用剩余次数降低玩家对 `保底计数` 的误读。
- 结果卡使用 `SW-ART-010` 秘籍卡牌框和 `SW-ART-014` 奖励图标；单次、十连、重复补偿、铜钱不足状态均已留浏览器截图。
- 当前奖励池覆盖普通残页、铜钱返还、外观、成长碎片、稀有心法碎片和称号卷轴；后续可在 `SW-META-002` 平衡阶段微调权重和奖励名。

异常状态：

| 状态 | 表现 | 规则 |
| --- | --- | --- |
| 铜钱不足 | 按钮置灰，显示 `铜钱不足` | 不弹充值入口 |
| 存档写入失败 | 非阻塞提示 `本地存档失败，请稍后再试` | 不扣铜钱或回滚扣除 |
| 结果重复 | 显示原奖励 + 补偿 | 补偿必须写档 |
| 保底触发 | 显示 `保底触发` | 不暗改概率表 |

## 奖励强度边界

翻阅秘籍可以给：

- 外观。
- 称号。
- 招式皮肤。
- 小幅局外成长碎片。

不能给：

- 付费专属强力招式。
- 通关必需道具。
- 直接跳过头目。
- 直接购买铜钱。
- 限时错过压力。

MVP 中翻阅秘籍来源的长期战力加成上限约为 15%。

## 存档结构

```json
{
  "schemaVersion": 1,
  "copper": 0,
  "bestTimeSeconds": 0,
  "bestKills": 0,
  "bestLevel": 1,
  "bossDefeated": false,
  "metaUpgrades": {
    "max_hp": 0,
    "move_speed": 0,
    "pickup_radius": 0
  },
  "scriptureGacha": {
    "starter_scripture_pool": {
      "pulls": 0,
      "pityCounter": 0
    }
  },
  "collection": {
    "skins": [],
    "titles": [],
    "fragments": {}
  },
  "settings": {
    "masterVolume": 1.0,
    "musicVolume": 0.6,
    "sfxVolume": 0.8,
    "muted": false,
    "lowVfxMode": false
  }
}
```

规则：

- 读档失败时重建默认存档。
- 写档失败时给出非阻塞提示，不能导致战斗崩溃。
- 存档版本升级必须有迁移函数。
- 不保存姓名、手机号、账号、位置等隐私数据。

## 验收

- 胜利和失败都能进入 `战后清点`。
- 铜钱计算符合公式，刷新页面后铜钱保留。
- 铜钱不能通过充值、广告、每日任务或外部入口获得。
- 3 个局外成长都有最高等级和成本。
- 翻阅秘籍只消耗铜钱，概率公开，重复有补偿。
- 连续 20 抽必定至少出现 1 个 `rare` 或以上。
- 没有商城、充值、广告、体力、限时礼包、付费抽取入口。
