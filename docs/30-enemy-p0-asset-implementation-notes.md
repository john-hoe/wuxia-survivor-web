# 30 Enemy P0 Asset Implementation Notes

> Archived 1× authoring note. The current runtime asset uses a 192×192 physical
> frame (2× the 96×96 logical size). Consult `artManifest.ts` before producing
> replacement sheets.

## 目的

本文只服务 `SW-COMBAT-001`：敌人生成、追踪、接触伤害。本轮不生成正式 PNG，不改工程代码，只把 `enemy_bandit_grunt_walk` 的 P0 可接入视觉方案写清楚，让工程可以先用程序 fallback，后续再无缝替换 spritesheet。

第一性原则：

- 敌人视觉的第一目标是让玩家知道“谁在靠近我、是否碰到我、为什么掉血”。
- P0 fallback 不能只是同色圆点；至少要靠颜色、尺寸、轮廓、层级 4 个维度和少侠、背景、掉落、危险反馈区分。
- 视觉半径可以大于碰撞半径，但不能暗示比规则更大的接触伤害范围。

| type | `enemy` |

### 程序绘制形状

建议每帧在 `96x96` 透明画布中心绘制，视觉中心固定在 `(48, 52)` 附近，脚底可略低于中心。

| 层级 | 形状 | 尺寸/位置 | 颜色 | 作用 |
| ---: | --- | --- | --- | --- |
| 1 | 椭圆阴影 | 中心 `(48, 68)`，宽 44，高 14，alpha 0.18 | `#1E1714` | 贴地，不参与碰撞 |
| 2 | 圆角梯形身体 | 上宽 26，下宽 38，高 42，中心 `(48, 50)` | `#9B5438` | 基础人形剪影 |
| 3 | 深色描边 | 包住身体和头部，2-3px | `#5B2F28` | 和背景、少侠分离 |
| 4 | 头部圆/椭圆 | 中心 `(48, 25)`，宽 24，高 20 | `#8B4934` | 山贼头部 |
| 5 | 头巾小角 | 头部左上或右上三角，长 8-10px | `#5B2F28` | 64px 下的身份特征 |
| 6 | 手臂短块 | 两侧 8x20 左右，随帧摆动 2-4px | `#7A3F2F` | 走路动势 |
| 7 | 木棍/短刀突起 | 单侧斜线或小矩形，长 18-24px，宽 4-5px | `#7A4A2B` | 敌人威胁点 |
| 8 | 布衣高光 | 胸前短斜条或肩部小块 | `#C77B4B` | 防止暖棕糊成一团 |

帧变化只做低成本摆动，不改变碰撞半径：

| 帧 | 变化 |
| ---: | --- |
| 1 | 左肩前压 3px，木棍向右后方倾斜 |
| 2 | 身体回中，头巾角保持可见 |
| 3 | 右肩前压 3px，木棍向左后方倾斜 |
| 4 | 身体回中并下沉 1px |

### 尺寸和半径关系

- `collisionRadius = 16px`：只用于接触伤害判定。
- `visualRadius = 34-38px`：山贼主体剪影范围，不含地面阴影和极短武器突起。
- 武器突起不能超过主体外缘 16px 以上，避免玩家误以为“棍子碰到就扣血”。
- 受击闪烁、死亡碎片、命中光不能扩大接触伤害暗示。

## 对比要求

### 和少侠区分

| 项 | 少侠 | 山贼喽啰要求 |
| --- | --- | --- |
| 主色 | 白青 `#EAF9F3` / 青绿 `#39D6B5` | 暖棕 `#9B5438`，禁止大面积白青 |
| 轮廓 | 斗笠、披风、朝向箭头 | 圆角梯形身体、头巾角、短武器 |
| 可见优先级 | 最高，80 敌包围仍能定位中心 | 可包围少侠，但不能盖掉少侠白青轮廓 |
| 闪烁 | 受伤白/红闪、无敌细环 | 受击只短闪，不使用少侠无敌环 |

量化底线：

- 80 个山贼围住少侠时，少侠主体可见面积应 >=35%。
- 少侠边缘描边或外发光在静止截图中至少连续可见 120 度以上。
- 山贼单体不得使用面积超过 10% 的白青或青绿。

### 和背景区分

`青石山道` 背景主色是低饱和灰青。山贼必须比背景更暖、更实、更有描边：

- 山贼主色暖棕，背景不使用大面积同暖棕人物形状。
- 背景高对比碎石不能聚成山贼大小的人形块。
- 山贼描边在灰阶截图中仍要比背景暗缝更连续。
- 地面阴影 alpha <=0.22，不能变成黑色敌人主体。

### 和 HUD/掉落/危险反馈区分

| 对象 | 禁止混淆点 |
| --- | --- |
| HUD | 山贼不能用 HUD 铜边金 `#B8894B` 作为主色，避免像 UI 图标 |
| 铜钱 | 山贼高光不使用大面积金黄 `#D8A642`，不画圆形方孔 |
| 内力 | 山贼不使用蓝青光环，不像可拾取奖励 |
| 回血 | 不使用药绿主体，不画十字或药丸形 |
| 危险红橙 | 不使用 `#E24A36` / `#FFB14A` 作为主体或预兆，避免抢头目危险语义 |

## SW-COMBAT-001 视觉验收建议

### 80 敌包围截图

截图内容：

- 少侠位于屏幕中心附近。
- 80 个 `enemy_bandit_grunt_walk` 在少侠半径 `160-260px` 范围内包围。
- 至少 20 个敌人处于接触边缘或近身压迫位置。
- 背景使用青石山道 fallback，HUD 正常显示。

通过线：

- 3 秒内能指出少侠中心。
- 3 秒内能判断包围者是敌人，不是铜钱、内力或背景碎石。
- 山贼重叠后仍能形成“暖棕敌群”，但不把少侠白青轮廓吞掉。
- 同屏 80 个山贼时，fallback 不出现大量高频闪烁或不可读噪点。

### 接触伤害截图/短录屏

建议保留连续 3 张截图或 1 段短录屏：

| 时刻 | 应看到 |
| --- | --- |
| 接触前 | 山贼接近少侠，碰撞暗示来自身体中心，不来自武器长尾 |
| 扣血帧 | 少侠闪白/闪红，屏幕边缘红闪或脚下血条出现 |
| 扣血后 0.6s 内 | 少侠有无敌闪烁/细环，敌人仍可移动但不连续扣血 |

通过线：

- 扣血反馈在伤害结算后 `<=0.2s` 可见。
- 一次接触只造成一次可理解的扣血，不出现同帧多敌叠加导致血量瞬间不明原因跳变。
- 山贼本体不需要红色危险预兆；接触伤害由“敌人碰到少侠 + 少侠受伤反馈”解释。

### 受伤无敌截图

截图内容：

- 少侠处于敌群接触中。
- HUD 血量已经下降。
- 少侠显示 0.6 秒无敌状态。

通过线：

- 无敌表现只属于少侠，不出现在山贼身上。
- 无敌细环或闪烁不被误认为护体真气技能。
- 敌人仍保持暖棕本体，不随少侠闪白一起变成友方或奖励。

### 暂停静止截图

截图内容：

- 游戏处于暂停页或暂停遮罩。
- 屏幕上保留若干山贼、少侠、HUD。

通过线：

- 山贼动画、追踪、接触伤害视觉状态应冻结。
- 暂停遮罩不应让山贼和少侠完全不可见，建议遮罩 alpha `0.45-0.6`。
- 暂停时截图仍能看出山贼围攻态势，不误判为死亡或战后结算。

## manifest 字段建议

工程 manifest 可以先用程序 fallback，字段保持后续 PNG 替换兼容。

```ts
{
  id: "enemy_bandit_grunt_walk",
  type: "enemy",
  path: "assets/enemies/enemy_bandit_grunt_walk.png",
  fallback: "shape:bandit_grunt",
  required: true,
  frames: 4,
  collisionRadius: 16,
  visualRadius: 36,
  usage: "山贼喽啰行走；SW-COMBAT-001 敌人生成、追踪、接触伤害 P0 基础慢怪",
  tags: ["enemy", "bandit", "grunt", "walk", "p0", "sw-combat-001"]
}
```

字段口径：

| 字段 | 说明 |
| --- | --- |
| `id` | 资产稳定 id，工程和后续 PNG 都沿用 |
| `type` | 本资产为 `enemy`，不要写成 `character` 或 `vfx` |
| `path` | 正式 PNG 路径；没有 PNG 时仍可保留目标路径 |
| `fallback` | 程序 fallback 标识，建议 `shape:bandit_grunt` |
| `required` | `true`，没有正式图也必须有 fallback |
| `frames` | 4，fallback 和 spritesheet 保持一致 |
| `collisionRadius` | 16，必须和敌人规则一致 |
| `visualRadius` | 建议 36，允许 34-38 |
| `usage` | 写清用途和任务来源，便于后续清理 |
| `tags` | 用于筛选 P0、敌人、山贼、战斗任务 |

## 禁止项

- 不使用《Survivor.io》或其他商业游戏的角色、敌人、图标、截图、描摹轮廓或配色复刻。
- 不使用素材站未授权商业素材。
- 不把山贼画成少侠同色白青、青绿披风或青白剑气。
- 不把山贼画成铜钱金色圆形、方孔钱、可拾取物轮廓。
- 不把山贼主体做成危险红橙，危险红橙保留给头目预兆和受伤反馈。
- 不加入血腥肢解、现代枪械、赛博霓虹、修仙大法阵。
- 不用大面积透明外发光解决识别问题；山贼靠剪影和描边读清。
