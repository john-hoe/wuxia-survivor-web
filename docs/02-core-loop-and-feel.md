# 02 Core Loop And Feel

## 核心循环

```mermaid
flowchart LR
    A["移动躲避"] --> B["自动招式"]
    B --> C["击杀江湖敌人"]
    C --> D["掉落内力"]
    D --> E["领悟三选一"]
    E --> F["招式构筑增强"]
    F --> G["更强怪潮"]
    G --> H["头目或战后清点"]
    H --> I["局外成长"]
    I --> A
```

## 第一性原则

这个类型的爽感来自三个东西叠加：

1. 操作负担低：用户只需要控制少侠移动。
2. 反馈频率高：不断击杀、吸内力、领悟。
3. 压力可读：江湖敌人越来越多，但用户知道自己为什么失败。

如果用户需要频繁按攻击键、看复杂菜单、读长文本，核心就偏了。

## 节奏目标

| 时间点 | 应发生的事情 |
| ---: | --- |
| 0:00 | 进入青石山道，少侠可移动 |
| 0:10 | 第一批山贼靠近 |
| 0:20 | 第一次领悟 |
| 1:00 | 用户已经形成一个明显招式方向 |
| 2:00 | 新敌人出现，压力变化 |
| 3:00 | 第一只木人机关或精英敌人出现 |
| 4:30 | 怪潮密度明显上升 |
| 6:00 | 黑风寨主出现或最终潮开始 |
| 6:30-8:00 | 胜利或失败战后清点 |

## 0 到 8 分钟调参表

| 时间 | 目标体验 | 主要调参手段 | 失败信号 |
| ---: | --- | --- | --- |
| 0-30s | 会移动、会击杀、看到内力 | 山贼数量、小内力掉落 | 25 秒内没领悟 |
| 30-60s | 恶犬加入，开始走位 | 恶犬比例、刷怪间隔 | 玩家被贴脸生成误伤 |
| 60-120s | 构筑初成，击杀稳定 | 领悟池、山贼/恶犬比例 | 击杀间隔 >2 秒 |
| 120-180s | 持盾山贼检验输出 | 持盾比例、血量 | 厚血怪过多堵死逃生方向 |
| 180-300s | 木人机关给阶段压力 | 精英间隔、回血掉落 | 精英无预警或看不清 |
| 300-360s | 头目前压 | 活跃敌人上限、持盾比例 | 帧率明显下降 |
| 360-480s | 头目战可读 | 普通怪潮降压、头目预兆 | 头目技能看不清或秒杀感 |

调整原则：

- 成长慢：先调掉落和怪潮密度，再动领悟阈值。
- 死亡不公平：先看生成距离、预兆和 HUD 遮挡，再降伤害。
- 压力不足：先提高目标存活敌人或敌人构成，不先提高所有敌人速度。
- 帧率不足：先降 VFX 和敌人上限，不删除核心反馈。

## 爽感指标

| 指标 | 目标 |
| --- | --- |
| 击杀间隔 | 前 2 分钟平均每 0.5 到 1.5 秒有击杀 |
| 领悟选择 | 每局至少 8 次，最多 18 次 |
| 构筑变化 | 每 2 到 3 次领悟应出现可感知变化 |
| 内力吸附 | 不要求像素级捡取，靠近后自动吸 |
| 敌人压迫 | 少侠应该常被包围，但有 1 到 2 个逃生方向 |
| 屏幕清晰度 | 敌人多时仍能看清少侠位置 |

## 失败体验

失败不能让用户觉得“被系统坑了”。

允许的失败原因：

- 走位被包围。
- 招式构筑缺少范围输出。
- 追内力光点过贪。
- 黑风寨主预兆没躲。

不允许的失败原因：

- 看不清自己在哪。
- 敌人突然刷新在脸上。
- 头目没有预兆。
- UI 遮住危险。
- 帧率下降导致操作失灵。

## 手感要求

| 项 | 目标 |
| --- | --- |
| 少侠移动 | 立即响应，不做重惯性 |
| 受伤反馈 | 屏幕轻闪、角色短暂无敌 |
| 内力吸附 | 有加速飞向少侠的曲线 |
| 领悟选择 | 清楚、快、不卡战斗节奏 |
| 招式命中 | 有短粒子或音效反馈 |
| 死亡重开 | 战后清点后 1 个按钮重开 |

## 最终试玩问题

这些问题只在游戏开发基本完成后再问朋友。开发阶段不使用朋友试玩作为完成门槛。

1. 你第一次领悟发生得快不快？
2. 你能说出这局主要靠什么招式吗？
3. 你死亡时知道为什么死吗？
4. 你是否想立刻再开一局？
5. 有没有任何付费、广告或日常压力感？

通过线：

- Q1-Q4 至少 70% 正向。
- Q5 必须 100% 回答“没有”。
