# 29 Character Drop VFX Art Spec

> Resolution note (2026-07-30): character dimensions in this historical
> production brief are 1× logical authoring sizes. Runtime sprite sheets are
> exported at 2× pixels per frame (for example hero 256×256 and basic enemy
> 192×192). `game/src/data/artManifest.ts` is the current machine-readable
> authority; do not export the 1× values below directly into the game.

## 目的

本文承接 `SW-ART-003`、`SW-ART-004`、`SW-ART-005`，把角色、敌人、头目、掉落、招式弹体、图标和 VFX 细化到可生产、可接入、可验收的规格。

`SW-COMBAT-001` 山贼喽啰程序 fallback、80 敌包围、接触伤害、受伤无敌和暂停静止截图的工程接入补充见 [30 Enemy P0 Asset Implementation Notes](30-enemy-p0-asset-implementation-notes.md)。

`SW-COMBAT-002` 游龙剑气弹体、命中和击杀 P0 程序 fallback 接入补充见 [31 Yulong Hit Kill VFX Implementation Notes](31-yulong-hit-kill-vfx-implementation-notes.md)。

第一性原则：

- 先保证战斗读局，再追求精修。
- 所有玩法对象必须靠颜色、轮廓、尺寸、动画至少 3 个维度区分。
- 角色和掉落不能依赖文字识别，图标在移动端 64px 下必须可读。
- VFX 必须在 0.2 秒内确认关键事件，但不能遮挡少侠、危险预兆和 HUD。
- 所有资产必须原创轻武侠江湖风，不使用《Survivor.io》或其他商业游戏原始素材、图标描摹、技能视觉复刻。

## 全局交接规则

| 项 | 规则 |
| --- | --- |
| 图片背景 | 角色、掉落、弹体、图标、VFX 使用透明 PNG 或 spritesheet；不得带烘焙背景板 |
| 帧序 | spritesheet 统一 `left-to-right`，单行优先；多行必须额外写 `rows/columns` |
| 锚点 | 角色、敌人、头目、掉落默认 `anchor: center`；冲击波和预兆默认中心锚点 |
| 边距 | 每帧至少 8px 透明边距，大范围 VFX 至少 16px 边距 |
| 中心稳定 | 角色/敌人连续帧视觉中心跳动 <=4px，头目 <=6px |
| 描边 | 少侠 3px 深描边或 4px 外发光；敌人 2-3px 深描边；头目 3-4px 深描边 |
| 禁用 | 真实武侠 IP、现代枪械、赛博霓虹、修仙满屏法阵、商业游戏原图或图标复刻 |

动效：

- 内力：4 帧闪烁，8fps，缩放 `0.92-1.08`，周期 0.8-1.2s。
- 铜钱：4 帧轻旋，8fps，亮边扫过一次，周期 1.2-1.6s。
- 回血：4 帧脉冲，8fps，低血量时边缘亮度可提高 15%。

透明背景要求：

- 掉落 PNG 透明背景，禁止白底、黑底、旧纸底板。
- 外发光 alpha 不超过 0.45，避免与 VFX 或危险范围混淆。
- 32px 下不能依赖文字、细小纹样或复杂明暗识别。

### 全局 VFX 预算

| 项 | 桌面 | 移动端 | 低画质 |
| --- | ---: | ---: | ---: |
| 常驻活跃 VFX | <=80 | <=60 | <=40 |
| 爆发峰值 VFX | <=160，持续 <=1s | <=100，持续 <=1s | <=70，持续 <=0.7s |
| 命中 VFX | <=40 | <=30 | <=24 |
| 击杀 VFX | <=30 | <=22 | <=18 |
| 吸附尾迹 | <=80 | <=60 | <=40 |
| 大范围 VFX | <=3 | <=2 | <=1 |
| 伤害数字 | <=40，可关闭 | <=24，可关闭 | 关闭 |

低画质降级顺序：

1. 关闭伤害数字。
2. 命中和击杀 VFX 上限降低 40%-60%。
3. 吸附尾迹长度降低 50%。
4. 大范围友方 VFX 帧数减半，保留首尾关键帧。
5. 头目预兆只降帧数和粒子，不降时长、不降边线可见度。
