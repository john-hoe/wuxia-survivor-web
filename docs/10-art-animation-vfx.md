# 10 Art Animation VFX

## 目的

美术、动画和特效不是最后装饰。对武侠 survivor-like 来说，它们直接决定用户能不能看清局面、理解伤害、感到成长和愿意再开一局。

第一性原则：

- 美术负责识别：少侠、江湖敌人、掉落、危险、奖励必须一眼区分。
- 动画负责状态：移动、受击、死亡、领悟、头目预兆必须让用户知道发生了什么。
- 特效负责反馈：命中、击杀、拾取、领悟、进阶必须在 0.2 秒内给到正反馈。
- 性能优先：同屏江湖敌人多时，视觉反馈要清楚，但不能把帧率打崩。

## 风格方向

MVP 不复刻《Survivor.io》的美术、图标、角色或技能表现。

当前风格基线以 [12 Wuxia Style And Level](12-wuxia-style-and-level.md) 为准：原创轻武侠江湖风，首关是 `青石山道`。

推荐方向：

- 俯视 2D。
- 高对比剪影。
- 青白剑气、淡绿掌风、银色暗器。
- 江湖敌人颜色和少侠颜色明显分离。
- 青石山道低噪声，不能抢过角色和掉落物。
- UI 清楚、厚实、适合手机触控。

禁止方向：

- 少侠、江湖敌人、内力、铜钱都用同色圆形或方块。
- 招式特效过亮，挡住敌人和少侠。
- 青石山道纹理过细，导致小怪和内力光点看不清。
- 头目技能没有预兆，只靠突然扣血。
- 使用《Survivor.io》或其他商业游戏的原始素材、图标、角色或技能视觉。

## 颜色和识别规则

| 类型 | 建议颜色方向 | 说明 |
| --- | --- | --- |
| 少侠 | 青绿/白色高亮 | 始终最高识别优先级 |
| 普通江湖敌人 | 暖色/暗红/紫灰 | 与少侠分离 |
| 精英/头目 | 更高饱和度 + 外圈 | 远看能认出威胁 |
| 内力光点 | 蓝/青 | 不与铜钱混淆 |
| 铜钱 | 金黄 | 不与危险黄色完全一致 |
| 危险范围 | 红/橙，半透明 | 只用于伤害预兆 |
| 友方招式 | 青/白/绿色系 | 与危险范围分离 |

量化识别门槛：

- 静止截图 3 秒内能指出少侠、最近敌人、内力光点、铜钱、头目或危险范围。
- 少侠被 80 个敌人包围时，仍能看见少侠轮廓。
- 危险范围透明度建议 35% 到 55%，不能盖住少侠。

## 性能预算

| 项 | MVP 预算 |
| --- | ---: |
| 同屏普通江湖敌人 | 80 到 180 |
| 同屏投射物 | 40 到 120 |
| 常驻活跃 VFX | <=80 |
| 爆发峰值 VFX | <=160，持续不超过 1 秒 |
| 伤害数字 | 同屏 <=40，可关闭 |
| 单张 sprite sheet | 建议 <=2048x2048 |
| 首包美术体积 | MVP 建议 <=10MB |
| 桌面目标 | 60 FPS |
| 移动端目标 | 45 到 60 FPS |

性能策略：

- VFX 使用对象池。
- 低画质模式降低粒子数量、关闭伤害数字、减少尾迹。
- 避免每个敌人都带复杂粒子。
- 头目技能可以华丽，但必须短时爆发。

## 开发顺序

1. 先做 P0 视觉基线：少侠、1 个江湖敌人、1 个招式、内力光点、命中、死亡、吸附。
2. 再做战斗闭环。
3. 然后补 3 类江湖敌人、铜钱、领悟卡和基础 UI。
4. 再做头目预兆和技能 VFX。
5. 最后做抽秘籍揭示、稀有度光效和视觉打磨。

不要等代码全部完成后再补视觉反馈。每个核心行为第一次实现时，就要有最小动画或特效。

## 验收

P0 通过必须满足：

- 少侠、敌人、内力光点、铜钱、危险范围 3 秒截图可识别。
- 命中、击杀、拾取、领悟、受伤和头目预兆都有视觉反馈。
- 同屏 120 江湖敌人时，桌面仍接近 60 FPS。
- 移动端 3 分钟运行不崩溃，少侠位置可读。
- 调试面板缺失资产数为 0。
- 不使用任何商业游戏原始素材。
