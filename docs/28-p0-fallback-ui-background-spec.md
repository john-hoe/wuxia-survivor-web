# 28 P0 Fallback UI Background Spec

## 目的

本文承接 `SW-ART-002` 和 `SW-ART-006`，给 Codex 工程在正式资产未完成前可直接接入的 P0 视觉占位、UI fallback 和 `青石山道` 背景方案。

角色、掉落、招式图标和 VFX 的正式制作级规格见 [29 Character Drop VFX Art Spec](29-character-drop-vfx-art-spec.md)。

第一性原则：

- 先保证识别，再追求精修。
- fallback 也必须是有意设计的临时美术，不允许全员同色圆点。
- 所有玩法对象必须通过颜色、尺寸、轮廓、层级至少 3 个维度区分。
- 背景和 UI 服务战斗判断，不能抢少侠、掉落和危险预兆。
- 只做原创轻武侠江湖风，不使用《Survivor.io》或其他商业游戏原始素材、图标描摹、技能视觉复刻。

## 适用边界

P0 fallback 允许使用 Phaser 程序化图形、简单 PNG 或 spritesheet 占位。工程接入时优先满足本文的尺寸、颜色、透明度、层级和可读性验收。

非目标：

- 不要求本轮生成最终角色、敌人、UI、背景 PNG。
- 不改变任务状态、dashboard、`current-status.md` 或 `next-step.md`。
- 不改 Phaser 代码或数值规则。
- 不用视觉表现替代碰撞、伤害、拾取、结算等规则裁判。

## 全局视觉规则

### 画面优先级

| 优先级 | 对象 | 视觉要求 |
| ---: | --- | --- |
| 1 | 少侠、危险范围、当前受伤反馈 | 最高对比，任何情况下不能被背景或 VFX 淹没 |
| 2 | 近身敌人、头目、精英、投射物 | 轮廓清楚，能判断威胁方向 |
| 3 | 内力、回血、铜钱、拾取尾迹 | 可拾取物不与危险色混淆 |
| 4 | HUD、领悟、暂停、结算、秘籍页面 | 信息清楚但不遮少侠半径 180px |
| 5 | 背景地表、竹影、碎石、远景门楼 | 低饱和、低噪声、不可误判为拾取或危险 |

### 最小对比和透明度

| 项 | 标准 |
| --- | --- |
| 少侠外轮廓 | 至少 3px 深描边或 4px 外发光，占位尺寸 128x128 内实际主体高度 78-92px |
| 敌人与少侠色相差 | 主色 hue 视觉上明显分离；截图转灰阶后仍靠轮廓区分 |
| 危险范围透明度 | 填充 alpha `0.35-0.55`，边缘 alpha `0.65-0.85` |
| 友方大范围 VFX 透明度 | 填充 alpha `0.18-0.35`，不能盖住危险范围超过 0.5 秒 |
| 背景噪声亮度差 | 单个 1024 tile 内明暗差控制在约 12%-18%，高对比小点每 256x256 不超过 8 个 |
| 移动端最小可点尺寸 | 普通按钮点击区 >=120x64，主按钮高度 >=72，暂停触控区 >=72x72 |

## SW-ART-006：UI 方案

### UI 共同规格

| 项 | 桌面 | 移动端 |
| --- | ---: | ---: |
| 页面安全边距 | >=16px | >=24px |
| 正文最小字号 | 16px | 18px |
| 次要说明最小字号 | 14px | 16px |
| 主按钮高度 | 64-80px | >=72px |
| 普通按钮点击区 | >=120x48 | >=120x64 |
| 卡片圆角 | 8px | 8px |
| 面板阴影 | 只允许轻微墨色阴影 alpha <=0.25 | 同桌面 |
| 常驻 HUD 避让 | 少侠半径 180px 内不放常驻 HUD | 同桌面 |

玩家可见文案必须沿用现有规范：`血量`、`等级`、`内力`、`铜钱`、`招式`、`领悟`、`进阶`、`战后清点`、`翻阅秘籍`。不得出现 `HP`、`XP`、`金币`、`武器`、`升级`、`抽卡`、`Gacha`、`充值`、`广告`。

### 主菜单

目标：打开网页后 5 秒内点击 `开始闯荡` 进入 `青石山道`。

布局：

| 区域 | 位置 | fallback 方案 | 尺寸/间距 | 验收 |
| --- | --- | --- | --- | --- |
| 背景 | 全屏 | 青石山道低噪声背景 + 远处山寨门楼淡影 | 背景亮度低于 UI 面板约 20% | 3 秒内看出轻武侠山道 |
| 标题 | 上方 12%-18% | `青石山道`，旧纸/墨色文字样式由工程文本渲染 | 移动端标题不超过 2 行 | 不放长剧情 |
| 少侠剪影 | 中心偏上 | `fallback_hero_shaoxia` 放大 1.2-1.4 倍，后方淡竹影 | 不遮按钮 | 一眼知道玩家角色 |
| 主按钮 | 中下 | `开始闯荡`，primary button | 宽 280-360，高 >=72 | 5 秒内可开始 |
| 次按钮 | 主按钮下 | `翻阅秘籍`、`设置`，secondary button | 间距 >=12 | 无存档时秘籍可置灰 |
| 底部信息 | 底部安全区 | 当前铜钱、最高时间、最高击杀 | 最多 2 行 | 不像商城入口 |

程序化接入：

- 背景先使用 `ground_qingshi_base` 色块 + 路带曲线 + 门楼剪影。
- 面板可以不用整张图，使用半透明墨灰矩形、8px 圆角、1-2px 铜边。

### 地表噪声

| 项 | 标准 |
| --- | --- |
| 主背景平均亮度 | 约 30%-42%，不得接近内力/铜钱亮度 |
| 青石缝线 | 宽 1-3px，alpha 0.15-0.28，不连续形成 UI 边框 |
| 高亮石块 | 每 256x256 不超过 6-8 个，亮度不超过背景平均 +18% |
| 红橙元素 | 地表禁用高饱和红橙；破旗红色面积每屏 <=1.5% |
| 蓝青元素 | 地表禁用高亮蓝青；水迹或青苔不可接近 `#49D8FF` |
| 重复打散 | 1024 tile 可镜像/90 度旋转；路带边缘用 alpha 软化 |

程序化实现建议：

- 先铺 3x3 个 1024 背景块，随 camera 循环复位。
- 用 2-3 层低 alpha 多边形模拟青石，不需要真实 tilemap 碰撞。
- 地表随机点尺寸控制在 2-6px，避免看起来像内力小点。
- 竹影使用暗绿/墨色大形，不使用亮绿小点。

### 边缘提示和节奏变化

| 时间 | 背景变化 | 数值建议 | 目的 |
| ---: | --- | --- | --- |
| 0-30s | 清晨山道、低密度竹影 | `propDensityScale = 0.8` | 玩家确认移动和第一批山贼 |
| 30-120s | 碎石和杂草略增 | `propDensityScale = 1.0` | 打散重复，不增噪声 |
| 120-180s | 远处旗影/木桩增多 | `distantGateAlpha = 0.08-0.14` | 暗示山寨方向 |
| 180-300s | 木人机关边缘预警更常见 | 精英预警最多 2 个 | 给高价值敌人提示 |
| 300-360s | 门楼剪影更明显，风尘线出现 | `distantGateAlpha = 0.18-0.28` | 头目前压 |
| 360s+ | 头目入场短暂压暗背景 | 背景暗度 10%-18%，持续约 1s | 强化头目入场，不遮危险 |

边缘提示规则：

- 竹林、碎石、木桩、门楼都不做碰撞承诺。
- 不出现可见硬墙，不暗示玩家不能走。
- 场景提示只改变氛围，不改变规则层。

### 背景性能预算

| 项 | P0 预算 |
| --- | ---: |
| 背景 chunk | 摄像机周围至少 3x3 个 1024 块；桌面最多 5x5，低端机保持 3x3 |
| 可见非交互装饰 | 每屏 <=24 组 |
| 高对比装饰 | 每屏 <=5 个 |
| 背景纹理单张 | <=1024x1024，特殊远景 <=1024x512 |
| 背景 draw calls | 桌面建议 <=18，移动端建议 <=12 |
| 背景总显存 | P0 建议 <=12MB |
| 首包美术总量 | 仍遵守 MVP 建议 <=10MB；程序化背景优先 |
| 桌面帧率 | 120 敌人 + 背景 + VFX 接近 60 FPS |
| 移动端帧率 | 80 敌人 + 低 VFX 模式 45-60 FPS |

低 VFX/低端模式：

- 背景装饰密度降低 40%-60%。
- 关闭细噪声动态层，只保留静态地表。
- 内力尾迹上限从 80 降到 40。
- 命中 VFX 上限从 40 降到 24。
- 死亡 VFX 上限从 30 降到 18。

### Manifest 建议

正式资产缺失时，manifest 可以先指向程序化 texture 或占位 PNG，但 `required` 和 `fallback` 语义必须清楚。

```ts
{
  id: "hero_shaoxia_move",
  type: "spritesheet",
  path: "generated:fallback_hero_shaoxia",
  width: 128,
  height: 128,
  frames: 1,
  frameRate: 0,
  usage: "少侠移动正式资产缺失时的 P0 fallback",
  fallback: "shape",
  required: true
}
```

规则：

- `fallback: "shape"` 用于玩法对象、危险预兆、核心 UI。
- `fallback: "tint"` 只用于同类低风险变体。
- `fallback: "hidden"` 只允许背景小装饰，不能用于少侠、敌人、掉落、危险、HUD。
- 调试面板仍需显示缺失正式资产，不应因为 fallback 存在就误判最终资产完成。
