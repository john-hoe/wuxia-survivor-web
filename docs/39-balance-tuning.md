结论：

- **240s+ 波次增长不过陡**：通量环比 +23% / +15% / +19%，清场/通量比稳定在 5.1–5.5，无刮痧段也无异常陡增。**waves.ts 数值不改**（240s+ 压力成长与构筑成长匹配；120–180s 的 +50% 通量跳变是持盾山贼登场的刻意"输出检验"，docs/02 明确要求）。
- 0–10s 比值 0.64 为暖机 soft backlog：alive 上限仅 8、喽啰 2 刀 1.8s vs 刷怪 0.85s，怪潮短暂堆积在 5–8 只，符合上手期低威胁设计，不改。
- Boss 期（360–480s）伴随潮比值 13.2，降压充分，符合"头目战可读"目标。

## 2. Boss HP / 预期击杀时间（目标 60–90s 窗）

有效 Boss DPS 修正：Boss 战伴随 70–120 只小怪，游龙索敌被分摊（按 55% 打 Boss）、震山 70% uptime、墨域 40% uptime、回风 50% uptime。

| 构筑（360s） | 有效Boss DPS | 黑风 5460（原4200） | 镖头 5980（原4600） | 坛主 6500（原5000） |
| --- | ---: | ---: | ---: | ---: |
| 弱（L13，无进阶） | ~75–85 | 64–73s（原 49–56s） | 70–80s | 76–87s |
| 中（L14–15，游龙进阶） | ~114 | 48s（原 37s） | 52s | 57s |
| 强（L16+，多技能满级） | ~123 | 44s（原 34s） | 49s | 53s |

- **原值断点（秒杀段）**：三 Boss 原击杀时间 34–45s，全部低于 60s 目标窗下沿，Boss 招式循环（冲撞 5.5s / 旋风 8s CD）只能演出 4–6 轮，"头目战可读"目标落空。
- 修正：三 Boss maxHp 各 +30%（单步调整上限），中位构筑击杀时间升至 48–57s，弱构筑进入 64–87s 窗。距 60–90s 全段达标仍差一步，见 §5 后续建议。
- Boss 接触/招式伤害（18/30/22）不动：战斗延长 30% 后 hero 100 血仍有 3–5 次容错 + 回血丸兜底，压力上升但在"失败公平"边界内。

## 3. 铜钱经济（保底 20 次 = 6000 铜钱）

公式：floor(存活/10) + 击杀×1 + 等级×8 + Boss赏金，难度系数 1.0；单次翻阅 300。

| 局型 | 铜钱 | 翻阅次数 |
| --- | ---: | ---: |
| 早期阵亡 120s / 击杀~110 / L5 | 162 | 0.5 |
| 中期阵亡 240s / 击杀~380 / L9 | 476 | 1.6 |
| Boss 前阵亡 350s / 击杀~700 / L13 | 839 | 2.8 |
| 通关 480s / 击杀~1050 / L16（赏金 170/210/250） | 1396–1476 | 4.7–4.9 |

- 到达 300s+ 的局 ≥2 次 ✓；通关局 ~5 次 ✓；保底 20 次 ≈ 4–5 个完整局，节奏合理。
- **经济断供段（无法在本分区修复）**：240s 前夭折局 0.5–1.6 次 < 2 次目标。铜式常量（击杀×1、等级×8、存活/10）在 `RunSettlementSystem.ts`、翻阅成本 300 在 `ScriptureScene.ts`，均非本批本代理分区 → 见 §5 建议。
- Boss 赏金递增 150/180/210 → 170/210/250（+13%/+16.7%/+19%）：与 +30% 战斗时长对等补偿，阶梯差由 +30/+30 平滑为 +40/+40，占通关总收入 12–17%，不破坏"MVP boss_bonus=150 量级"的设计意图。
