## 最终试玩通过线

这些指标只在游戏开发基本完成后的最终朋友试玩阶段判断。开发阶段不使用朋友试玩作为功能完成门槛。

| 指标 | 通过线 |
| --- | --- |
| 首次领悟时间 | 中位数 15 到 25 秒 |
| 单局时长 | 中位数 4 到 8 分钟，早期失败可接受 |
| 想再开一局 | >=70% |
| 死因可理解 | >=70% |
| 招式构筑可描述 | >=60% |
| 付费压力 | 0 人感到有付费/广告/日常压力 |
| 铜钱抽秘籍理解 | 100% 试玩者知道抽秘籍只消耗游玩铜钱 |

最终试玩进入条件：

- MVP 通过标准全部达到。
- `npm run build` 和 `npm run typecheck` 通过。
- 桌面和移动端都能完成至少 1 局或 8 分钟无崩溃运行。
- 已知 P0/P1 为 0。

## 开发者验收脚本

开发阶段由开发者自己手动测试，不需要朋友试玩：

1. 打开本地网页。
2. 确认主菜单显示 `开始闯荡`、`翻阅秘籍`、`设置`，且无商城、充值、广告、体力入口。
3. 点击 `开始闯荡` 进入游戏。
4. 移动 30 秒。
5. 确认斜向移动不比直线移动更快。
6. 朝一个方向连续移动 60 秒，确认没有可见硬墙、黑屏或刷怪断层。
7. 让少侠被山贼接触 1 次，确认扣血、无敌和受伤反馈。
8. 确认游龙剑气不按攻击键也会自动瞄准和攻击。
9. 击杀至少 10 个江湖敌人。
10. 确认敌人从屏幕外生成，最近生成距离不小于 220px。
11. 游玩到 60 秒，确认恶犬加入。
12. 游玩到 150 秒，确认持盾山贼加入。
13. 拾取内力并领悟 1 次。
14. 确认命中、击杀、内力吸附、领悟都有视觉反馈。
15. 确认领悟后招式或属性确实变化。
16. 确认命中、击杀、拾取、领悟、阵亡、按钮有声音或可静音。
17. 打开暂停页，确认战斗停止，再继续游戏。
18. 选择一个领悟。
19. 确认领悟期间敌人、投射物、计时器和内力光点不移动。
20. 继续游玩到死亡或 3 分钟。
21. 如果死亡，确认先出现 `力竭倒地` 阵亡过渡和死因提示，再进入战后清点。
22. 查看战后清点。
23. 重开一局。
24. 获得足够铜钱后进行 1 次翻阅秘籍。
25. 确认翻阅秘籍概率默认可见、铜钱不足状态清楚、结果卡和重复补偿可读。
26. 刷新页面，确认存档和声音设置仍在。

通过条件：

- 26 步都能完成。
- 无 P0/P1。
- 无任何收费入口。
