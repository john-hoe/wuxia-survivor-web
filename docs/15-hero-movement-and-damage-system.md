# 15 Hero Movement And Damage System

## 目的

少侠移动与受伤系统负责本局最基础的可玩性：

- 用户只控制移动。
- 少侠被江湖敌人或头目技能命中时扣血。
- 受伤、无敌、死亡和重开必须清楚。
- 移动端摇杆不能成为主要挫败来源。

这个系统不负责自动招式、敌人 AI、内力拾取或结算。

## 第一性原则

Survivor-like 的操作爽感来自低负担和高可控：

- 输入必须立即响应。
- 少侠不能像重物一样拖泥带水。
- 受伤必须可读，但不能频繁打断移动。
- 死亡应该来自走位、构筑或危险预兆判断，而不是碰撞规则含糊。

如果用户觉得“我按了但角色没走”或“我不知道为什么掉血”，这个系统失败。

## 基础属性

| 属性 | MVP 值 | 说明 |
| --- | ---: | --- |
| 最大血量 | 100 | 局内初始值 |
| 移动速度 | 220px/s | 默认直线速度 |
| 冲刺 | 不做 | MVP 不增加主动按钮 |
| 碰撞半径 | 18px | 少侠受击与敌人接触判定 |
| 视觉半径 | 24px 到 28px | 角色图像可大于碰撞半径 |
| 拾取半径 | 70px | 详细见内力系统 |
| 受伤无敌 | 0.6 秒 | 接触伤害后短暂无敌 |
| 低血量阈值 | 25% | HUD 和声音提示 |
| 脚下辅助血条常驻阈值 | 30% | 低血量时显示 |

## 输入规则

PC 输入：

- WASD。
- 方向键。
- 同时按相反方向时互相抵消。
- 斜向移动必须归一化，不能比直线更快。

移动端输入：

- 左下虚拟摇杆。
- 摇杆触控区建议为屏幕左下 38% 宽、45% 高。
- 摇杆死区为半径 10%。
- 摇杆最大输出半径为视觉摇杆半径的 70% 到 80%。
- 手指离开后输入立即归零。

输入向量：

```text
inputX = right - left
inputY = down - up
if length > 1: normalize
velocity = inputVector * moveSpeed
```

## 移动手感

MVP 使用即时速度，不做重惯性。

| 项 | MVP 值 |
| --- | ---: |
| 起步响应 | <=50ms |
| 停止响应 | <=50ms |
| 方向切换响应 | <=80ms |
| 加速度 | 不做或极轻 |
| 摩擦滑行 | 不做 |

如果后续觉得太生硬，可以加入 0.05 到 0.08 秒的速度平滑，但不能影响躲避。

## 关卡空间与技术边界

MVP `青石山道` 不做玩家可见硬边界。

设计目标：

- 体验上接近“无边界割草”，少侠连续朝一个方向移动也不会撞墙。
- 技术上仍然要有安全边界，用来控制刷怪、对象回收、背景循环和坐标精度。

MVP 规则：

- 不设置玩家能撞到的地图墙。
- 不用竹林、山石、山寨木桩做硬阻挡，只做背景和氛围物件。
- 背景使用可循环的山道、竹林、碎石纹理，跟随世界坐标重复铺开。
- 江湖敌人和掉落物只在少侠周围的活动半径内生成、更新和回收。
- 少侠连续朝任意方向移动 3 分钟，不应看到黑屏、空白边缘、硬墙或刷怪断层。

技术安全边界：

| 项 | MVP 值 |
| --- | ---: |
| 敌人生成距离 | 屏幕外 120 到 260px |
| 敌人回收距离 | 距少侠 1400px 以外 |
| 掉落物回收距离 | 距少侠 1600px 以外，或存在 60 秒 |
| 背景循环块 | 512px 或 1024px |
| 坐标重置阈值 | 任一轴绝对值 > 20000px |

坐标重置规则：

- 当少侠世界坐标任一轴超过 `20000px`，执行 origin rebase。
- 少侠坐标重置回接近 `(0, 0)`。
- 屏幕内敌人、投射物、掉落物、特效同步平移相同偏移量。
- 玩家不能看到跳变。
- 调试面板记录 `originRebaseCount`。

临时实现可以先不做复杂地图生成，但不能用可见墙代替无边界体验。

## 受伤规则

伤害来源：

| 来源 | MVP 伤害 | 触发 |
| --- | ---: | --- |
| 山贼喽啰接触 | 5 | 接触少侠碰撞半径；早期压力用，不能在前 2 分钟稳定围死玩家 |
| 恶犬接触 | 8 | 接触少侠碰撞半径 |
| 持盾山贼接触 | 14 | 接触少侠碰撞半径 |
| 木人机关接触 | 20 | 接触少侠碰撞半径 |
| 黑风寨主接触 | 18 | 接触少侠碰撞半径 |
| 黑风寨主冲撞斩 | 30 | 命中预警范围 |
| 黑风寨主旋风刀 | 22 | 命中环形刀气 |

接触伤害规则：

- 少侠和敌人碰撞圆相交时触发伤害。
- 扣血后进入 0.6 秒受伤无敌。
- 无敌期间不再受到接触伤害。
- 无敌期间仍可移动。
- 头目技能是否穿透无敌由头目规格决定；MVP 默认也遵守无敌，避免突然连死。

## 受伤无敌触发条件

受伤无敌只是一段防连扣保护，不是主动技能。

会触发无敌：

- 少侠受到江湖敌人接触伤害并实际扣血。
- 少侠受到头目技能伤害并实际扣血。
- 少侠受到未来地形危险伤害并实际扣血；MVP 暂无地形危险伤害。

不会触发无敌：

- 只是碰到敌人但已经处于无敌期间，没有再次扣血。
- 拾取内力光点、铜钱、回血药丸。
- 领悟完成后的 20 点调息回血。
- 使用或获得护体真气等防护招式。
- 领悟弹窗打开期间，因为规则层已暂停。
- 战后清点、暂停页、翻阅秘籍等非战斗页面。

持续时间：

- MVP 固定为 0.6 秒。
- 无敌时间从扣血成功后立刻开始计时。
- 连续受伤不会叠加延长无敌时间；MVP 不做叠加。

边界：

- 无敌只阻止伤害，不阻止碰撞、移动、拾取和招式释放。
- 无敌不是护盾，不吸收伤害、不反弹伤害、不显示为护体真气。
- 如果以后加入护盾招式，护盾应该先于扣血结算；没有实际扣血就不触发受伤无敌。

## 受伤反馈

受伤必须同时有至少两种反馈：

- 少侠闪白或闪红 0.12 到 0.18 秒。
- 屏幕边缘轻微红闪 0.15 到 0.25 秒。
- 脚下辅助血条显示 2 秒。
- 播放 `hero_hurt` 音效。

禁止：

- 只改血量数字，不给视觉反馈。
- 受伤时强制停顿超过 0.1 秒。
- 把屏幕红闪做得遮挡危险范围。

## 无敌表现

无敌期间：

- 少侠透明度或描边轻微闪烁。
- 闪烁频率建议 8 到 12Hz。
- 不影响移动和拾取。
- 不影响招式释放。
- 无敌结束后恢复正常显示。

无敌不是护盾，不显示为护体真气。护体真气属于招式系统，避免混淆。

## 血量显示

主血量：

- 常驻左上 HUD。
- 文案固定 `血量`。
- 示例：`血量 68/100`。

脚下辅助血条：

- 默认隐藏。
- 受伤后显示 2 秒。
- 血量低于 30% 时常驻。
- 宽度为少侠碰撞直径的 1.2 到 1.6 倍。
- 高度 4 到 6px。
- 距离脚底 8 到 14px。
- 不显示数字。

低血量提示：

- 血量低于 25% 时，HUD 血量变红或闪烁。
- 可播放低血量循环音，但必须可关闭。
- 低血量提示冷却至少 8 秒，避免烦躁。

## 死亡规则

当血量 `<= 0`：

- 少侠进入 `dead` 状态。
- 输入失效。
- 招式停止发射。
- 敌人和头目行为暂停或淡化，避免死亡后继续混乱。
- 播放死亡反馈 0.8 到 1.2 秒。
- 进入战后清点页。

死亡反馈：

- 少侠淡出或倒下。
- 屏幕轻微降饱和。
- 播放 `hero_die` 音效。
- 不使用夸张血腥表现。

阵亡过渡画面：

- 具体 UI 以 [21 HUD Pause Screen Flow Detail](21-hud-pause-screen-flow-detail.md) 的“阵亡过渡画面”为准。
- 中央文案固定 `力竭倒地`，不显示 `Game Over`。
- 过渡期间不显示重开按钮，避免玩家误以为没有结算收益。
- 过渡结束后进入 `战后清点`，失败局仍按 [20 Copper Meta Scripture System](20-copper-meta-scripture-system.md) 计算铜钱。

死因记录：

| cause id | 玩家提示 | 来源 |
| --- | --- | --- |
| `enemy_contact` | `被山贼围住` | 普通敌人接触伤害 |
| `hound_contact` | `被恶犬扑中` | 恶犬接触伤害 |
| `boss_contact` | `被黑风寨主撞倒` | 头目接触伤害 |
| `boss_charge` | `被冲撞斩击中` | 头目冲撞斩 |
| `boss_whirlwind` | `被旋风刀击中` | 头目旋风刀 |
| `unknown` | `血量耗尽` | 未记录到明确最后伤害 |

## 状态机

```text
alive
hurt_invincible
low_hp
dead
```

状态说明：

| 状态 | 输入 | 受伤 | 招式 | HUD |
| --- | --- | --- | --- | --- |
| alive | 可移动 | 可受伤 | 正常 | 正常 |
| hurt_invincible | 可移动 | 忽略接触伤害 | 正常 | 脚下辅助血条显示 |
| low_hp | 可移动 | 可受伤 | 正常 | 主血量强调，脚下辅助血条常驻 |
| dead | 禁用 | 不再处理 | 停止 | 转战后清点 |

`hurt_invincible` 和 `low_hp` 可以同时满足；实现时可用 flags，不一定要做互斥枚举。

## 碰撞规则

MVP 使用圆形碰撞：

```text
distance(hero.center, enemy.center) <= hero.radius + enemy.radius
```

建议：

- 少侠碰撞半径小于视觉轮廓，给用户一点容错。
- 敌人碰撞半径也应小于视觉轮廓，避免看起来没碰到却受伤。
- 头目技能范围必须以预警图形为准，命中范围不能大于预警范围。

## 回血规则

MVP 允许少量回血药丸，并允许每次领悟完成后触发一次小回血，用来缓冲早期构筑成型前的连续接触伤害。

| 来源 | 回血量 | 触发条件 | 备注 |
| --- | ---: | --- | --- |
| 回血药丸 | 25 | 拾取回血掉落 | `SW-WAVE-001` 或后续敌人掉落阶段接入 |
| 领悟调息 | 20 | 每次选择领悟后立即触发 | 不超过最大血量，不触发受伤无敌 |

回血不能超过最大血量。

回血反馈：

- 绿色小闪光。
- HUD 血量上升。
- 播放 `heal_pickup` 音效。

## 局外成长影响

局外成长可以影响：

- 最大血量。
- 移动速度。
- 拾取半径。

限制：

- MVP 单项最多 5 级。
- 移动速度局外加成总计不超过 15%。
- 最大血量局外加成总计不超过 25%。
- 不允许局外成长消除前 1 分钟压力。

## 验收

MVP 通过必须满足：

- PC WASD 和方向键都能移动少侠。
- 斜向移动不会比直线移动更快。
- 移动端虚拟摇杆可控制方向，松手后少侠停止。
- 少侠连续朝任意方向移动 3 分钟，不出现可见硬墙、黑屏、空白边缘或刷怪断层。
- 被山贼接触后扣血，并进入 0.6 秒无敌。
- 无敌期间接触敌人不会连续扣血。
- 无敌不是主动按钮，不会在拾取、领悟、回血或护体真气触发时启动。
- 受伤时至少出现 2 种反馈：角色闪烁、屏幕红闪、脚下辅助血条、音效。
- 血量低于 30% 时脚下辅助血条常驻。
- 血量低于 25% 时 HUD 有低血量提示。
- 血量归零后进入死亡状态，并能进入战后清点。
- 玩家可见 UI 使用 `血量`，不出现 `HP` 或 `生命`。

## 调参观察

开发者 3 分钟自测记录：

| 指标 | 目标 |
| --- | --- |
| 起步响应 | <=50ms |
| 停止响应 | <=50ms |
| 方向切换响应 | <=80ms |
| 非头目连续受伤间隔 | >=0.6 秒 |
| 首次死亡时间 | 新手目标 2 到 5 分钟 |
| 低血量可读性 | 3 秒内能发现 |

如果用户频繁觉得“没碰到也受伤”，优先缩小碰撞半径，不先降低伤害。

如果用户频繁觉得“被怪贴住跑不掉”，优先调敌人速度、碰撞半径和无敌时间，不先提高少侠基础速度。
