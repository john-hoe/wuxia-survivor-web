# 31 Yulong Hit Kill VFX Implementation Notes

## 目的

本文只服务 `SW-COMBAT-002`：游龙剑气自动释放、命中、击杀和基础反馈。本轮不生成正式 PNG，不改工程代码，只把 `skill_yulong_projectile`、`vfx_hit_light`、`vfx_enemy_die` 的 P0 程序 fallback 接入要求写清楚，让工程可以先用程序绘制，后续再无缝替换 spritesheet。

第一性原则：

- 弹体视觉的第一目标是让玩家在 0.2 秒内知道“招式已经释放、往哪里飞、命中了谁、谁被击杀”。
- P0 fallback 必须靠形状、颜色、尺寸、方向、层级和动效与少侠、山贼、内力、铜钱、危险红橙、HUD 区分。
- 视觉宽度可以大于命中半径，但不能暗示比规则更大的伤害范围。

## 适用范围

| 项 | 本轮要求 |
| --- | --- |
| 任务 | `SW-COMBAT-002` |
| 弹体 id | `skill_yulong_projectile` |
| VFX id | `vfx_hit_light`、`vfx_enemy_die` |
| 工程可用方案 | 程序 fallback，后续 PNG/spritesheet 替换 |
| 不做 | 正式 PNG、商业素材复刻、复杂粒子系统、额外招式、额外敌人、工程代码实现 |

## `skill_yulong_projectile` 程序 fallback

### 规格表

| 字段 | 建议值 |
| --- | --- |
| id | `skill_yulong_projectile` |
| type | `projectile` |
| fallback texture id | `fallback_skill_yulong_projectile` |
| 逻辑帧尺寸 | `96x32` |
| 帧数 | 4 |
| fps | 12 |
| 主色 | 青白 `#BFF8F1` |
| 辅色 | 青绿 `#39D6B5` |
| 高光 | 白芯 `#F4FFFC`，面积 <=18% |
| 外发光 | 青白，alpha <=0.32，宽 3-5px |
| 视觉宽度 | `70-86px` |
| 视觉高度 | `18-26px` |
| 命中半径 | `12-14px`，建议 P0 用 `13px` |
| 层级 | 高于敌人本体和背景；低于少侠受伤反馈、危险预兆、HUD、领悟/暂停 UI |

### 程序绘制形状

建议在 `96x32` 透明画布中心绘制，默认朝右，运行时按飞行向量旋转。

| 层级 | 形状 | 尺寸/位置 | 颜色 | 作用 |
| ---: | --- | --- | --- | --- |
| 1 | 低 alpha 外弧 | 从 `(14, 24)` 到 `(86, 8)` 的月牙弧，厚 7-9px | `#7FE9F2`，alpha 0.20-0.32 | 速度拖尾 |
| 2 | 主月牙剑弧 | 从 `(16, 22)` 到 `(84, 9)` 的弯弧，厚 5-7px | `#BFF8F1` | 主要剪影 |
| 3 | 内侧青绿刃线 | 沿主弧内侧短线，长 46-58px，厚 2-3px | `#39D6B5` | 和内力光点区分为“剑弧” |
| 4 | 尖端高光 | 右端尖三角或短梭形，长 10-14px | `#F4FFFC` | 明确飞行方向 |
| 5 | 尾部断光 | 左端 2-3 条短线，长 8-16px | `#A9F7FF`，alpha 0.35-0.55 | 速度感 |

帧变化只做低成本流动，不改变命中半径：

| 帧 | 变化 |
| ---: | --- |
| 1 | 月牙完整，尖端最亮 |
| 2 | 尾部断光后移 4px，外弧 alpha +0.05 |
| 3 | 主弧略短 4px，尖端拉长 2px |
| 4 | 尾迹淡出，回到帧 1 前的过渡 |

### 旋转、方向和速度感

- 默认美术朝右，工程按 `atan2(velocity.y, velocity.x)` 旋转到飞行方向。
- 尖端必须朝向速度方向，尾部断光必须在反方向。
- 旋转后不额外拉伸碰撞半径；命中仍按圆形半径或工程已有投射物规则判定。
- 速度感优先来自尾部断光、短拖尾和帧间亮度变化，不用大面积模糊。
- 静止截图中 3 秒内必须能判断剑气飞行方向；32px 缩放下仍要看出箭头/月牙尖端。

### 尺寸和判定关系

- `hitRadius = 12-14px`：只用于命中判定。
- `visualWidth = 70-86px`：用于读出剑气方向和速度，不代表整条尾迹都有伤害。
- 尾迹只承担方向和速度感，不暗示额外命中范围。
- 命中点建议取弹体前 55%-65% 的视觉位置；若工程用中心点命中，命中 VFX 必须贴近敌人中心而不是尾迹末端。

## `vfx_hit_light` 程序 fallback

### 规格表

| 字段 | 建议值 |
| --- | --- |
| id | `vfx_hit_light` |
| type | `vfx` |
| fallback texture id | `fallback_vfx_hit_light` |
| 逻辑帧尺寸 | `64x64` |
| 帧数 | 4 |
| fps | 30-40，或总时长驱动 |
| 持续时间 | `0.10-0.14s` |
| 主色 | 白青 `#D6FBFF` |
| 辅色 | 淡黄 `#FFE08A`，面积 <=20% |
| alpha | `0.85 -> 0` |
| 同屏预算 | 桌面 <=40，移动 <=30，低画质 <=24 |
| 层级 | 高于敌人本体；低于危险预兆、HUD、暂停 UI |

### 程序绘制形状

- 中心短闪：半径 10-14px 的白青圆闪，首帧 alpha 0.85。
- 四向小火花：4 条短剑光线，长度 14-22px，厚 2-3px，角度可随命中方向旋转。
- 淡黄只做极小撞击高光，不能成为主体色。
- 第 3 帧后中心缩小并淡出，不保留长尾。

低画质降级：

- 不再绘制 4 条火花，只保留中心白青闪和敌人短闪白。
- 同屏上限降到 24，单帧新建建议 <=8。
- 若超预算，合并 48px 内的多个命中点为 1 个闪光。

## `vfx_enemy_die` 程序 fallback

### 规格表

| 字段 | 建议值 |
| --- | --- |
| id | `vfx_enemy_die` |
| type | `vfx` |
| fallback texture id | `fallback_vfx_enemy_die` |
| 逻辑帧尺寸 | `96x96` |
| 帧数 | 6 |
| fps | 24-30，或总时长驱动 |
| 持续时间 | `0.20-0.28s` |
| 主色 | 继承敌人暖棕 `#9B5438` / 暗红棕 `#5B2F28` |
| 中心光 | 淡青白 `#BFF8F1` 或淡黄 `#FFE08A`，alpha <=0.5 |
| alpha | 碎片 `0.8 -> 0`，中心 `0.5 -> 0` |
| 同屏预算 | 桌面 <=30，移动 <=22，低画质 <=18 |
| 层级 | 高于敌人本体；低于内力/铜钱掉落、危险预兆、HUD |

### 程序绘制形状

- 中心缩小：敌人中心出现 18-24px 暖棕压缩闪，0.08s 内淡出。
- 碎片外散：4-6 个小梯形/短条从中心向外移动 14-28px，使用敌人暖棕和暗红棕。
- 击杀确认光：中心 1 个淡青白或淡黄短闪，最高 alpha 0.5，持续不超过 0.08s。
- 不使用血腥碎块、红色喷溅或大面积黑烟。

低画质降级：

- 碎片数量从 6 降到 3。
- 关闭中心光或只保留 1 帧。
- 同屏上限降到 18；爆发击杀时优先保留离少侠最近 12 个和精英/头目附近击杀反馈。

## 混淆禁用规则

| 对象 | 禁用规则 |
| --- | --- |
| 少侠 | 游龙剑气和命中 VFX 可用青白，但不得画成斗笠、披风、人形、少侠无敌环；弹体不得覆盖少侠主体超过 0.2s |
| 山贼 | 击杀 VFX 可继承暖棕碎片，但弹体主体不得暖棕；命中闪不能让山贼长期变成友方青白单位 |
| 内力 | 内力是蓝青圆点/光团；游龙必须是月牙剑弧，有尖端和尾迹，不能做成圆形光珠 |
| 铜钱 | 禁止大面积金黄、圆形方孔、铜边扫光；淡黄只允许做命中瞬间小高光 |
| 危险红橙 | `#D84A35`、`#FF6B4A`、`#FFB14A` 不得作为友方弹体/VFX 主色；红橙保留给受伤和头目危险预兆 |
| HUD | 弹体/VFX 不使用 HUD 铜边框、面板底板、图标圆底；不得在 HUD 层绘制战斗 VFX |
| 背景青石 | 青白外发光 alpha <=0.32，避免在灰青背景上糊成一片雾 |

## 截图验收建议

### 自动释放/飞行截图

至少保留 1 张 `skill_yulong_projectile` 飞行截图：

- 少侠、至少 3 个山贼、1 条正在飞行的游龙剑气、HUD 同屏可见。
- 剑气离少侠 80-240px，避免刚出生贴身看不出方向。
- 背景使用青石山道 fallback。

通过线：

- 3 秒内能指出剑气飞行方向。
- 剑气不被误认为内力、铜钱、山贼或 HUD 图标。
- 剑气视觉宽度清楚，但不暗示整条尾迹都有伤害。

### 命中截图

至少保留 1 张命中截图或短录屏关键帧：

- 剑气命中山贼，`vfx_hit_light` 或敌人闪白已出现。
- 命中反馈在命中结算后 `<=0.2s` 可见。
- 如果同屏多次命中，至少 1 个命中点清楚贴近被命中的敌人。

通过线：

- 3 秒内能指出“哪个敌人被打中”。
- 命中反馈不遮挡少侠和危险红橙预兆。
- 命中 VFX 不像铜钱拾取、领悟爆发或头目危险范围。

### 击杀截图

至少保留 1 张击杀截图或短录屏关键帧：

- 山贼死亡瞬间出现 `vfx_enemy_die`，随后内力掉落或击杀计数反馈可见。
- 击杀反馈在死亡结算后 `<=0.2s` 可见。
- 击杀 VFX 总时长在 `0.20-0.28s`，播完回收。

通过线：

- 3 秒内能判断敌人已经死亡，不是暂停、受伤无敌或被背景遮挡。
- 击杀碎片不遮挡死亡后内力掉落；掉落必须在 `<=0.2s` 内可见。
- 批量击杀时不会产生满屏红橙或高频闪烁。

## manifest 字段建议

工程 manifest 可以先保留正式 PNG 路径，同时启用程序 fallback。

```ts
{
  id: "skill_yulong_projectile",
  type: "projectile",
  path: "assets/skills/skill_yulong_projectile.png",
  fallback: "shape:yulong_projectile",
  required: true,
  frames: 4,
  frameRate: 12,
  width: 96,
  height: 32,
  usage: "游龙剑气普通弹体；SW-COMBAT-002 自动释放和命中 P0 fallback",
  tags: ["skill", "projectile", "yulong", "p0", "sw-combat-002"]
}
```

```ts
{
  id: "vfx_hit_light",
  type: "vfx",
  path: "assets/vfx/vfx_hit_light.png",
  fallback: "shape:hit_light",
  required: true,
  frames: 4,
  frameRate: 30,
  width: 64,
  height: 64,
  usage: "命中短闪；SW-COMBAT-002 命中反馈 P0 fallback",
  tags: ["vfx", "hit", "combat", "p0", "sw-combat-002"]
}
```

```ts
{
  id: "vfx_enemy_die",
  type: "vfx",
  path: "assets/vfx/vfx_enemy_die.png",
  fallback: "shape:enemy_die",
  required: true,
  frames: 6,
  frameRate: 24,
  width: 96,
  height: 96,
  usage: "敌人击杀消散；SW-COMBAT-002 击杀反馈 P0 fallback",
  tags: ["vfx", "enemy", "die", "kill", "p0", "sw-combat-002"]
}
```

字段口径：

| 字段 | 说明 |
| --- | --- |
| `id` | 资产稳定 id，工程和后续 PNG 都沿用 |
| `type` | `projectile` 或 `vfx`，不要写成 `ui`、`drop` 或 `enemy` |
| `path` | 正式 PNG/spritesheet 目标路径；没有 PNG 时仍保留目标路径 |
| `fallback` | 程序 fallback 标识，建议 `shape:yulong_projectile`、`shape:hit_light`、`shape:enemy_die` |
| `required` | `true`，没有正式图也必须有 fallback |
| `frames` | fallback 和 spritesheet 保持一致 |
| `frameRate` | 帧率建议；若工程按持续时间驱动，也保留该字段方便后续替换 |
| `width` / `height` | 单帧尺寸，不是整张 spritesheet 总尺寸 |
| `usage` | 写清用途和任务来源，便于后续清理 |
| `tags` | 用于筛选 P0、招式、VFX、战斗任务 |

## 禁止项

- 不使用《Survivor.io》或其他商业游戏的技能弹体、命中特效、击杀特效、截图裁切、描摹轮廓或配色复刻。
- 不使用素材站未授权商业素材。
- 不把游龙剑气画成圆形内力、铜钱、红橙危险预兆、HUD 图标或少侠无敌环。
- 不用大面积红橙表现友方命中/击杀，红橙语义保留给受伤和头目危险。
- 不加入血腥喷溅、肢解、现代枪械、赛博霓虹、修仙满屏法阵。
- 不让 VFX 长时间遮挡 HUD、少侠中心、危险预兆或死亡后掉落。
