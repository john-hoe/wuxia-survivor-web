# 01 MVP Scope

## MVP 目标

做一个 6 到 8 分钟可玩的 Web 武侠 survivor-like 原型，验证核心爽感：

移动躲避 -> 自动招式 -> 击杀掉内力 -> 领悟三选一 -> 招式构筑变强 -> 江湖怪潮加压 -> 头目检验 -> 战后清点 -> 再来一局。

## 必做内容

| 模块 | MVP 范围 | 验收 |
| --- | --- | --- |
| 少侠 | 1 个少侠，键盘和触控移动 | PC 和手机都能移动 |
| 攻击 | 3 种 P0 自动招式 | 不按攻击键也能持续输出 |
| 江湖敌人 | 3 类普通江湖敌人 + 1 类精英敌人 | 有速度、血量、体型和压力功能差异 |
| 首关头目 | 1 个首关头目 | 至少 2 种攻击模式 |
| 内力 | 内力光点自动吸附 | 15 到 25 秒内第一次领悟 |
| 领悟 | 领悟三选一 | 每次领悟暂停或慢动作选择 |
| 招式进阶 | 3 个招式进阶组合 | 用户能感到形态变化 |
| 美术 | 少侠、敌人、头目、招式、掉落物、UI 的 P0 资产 | 3 秒内能分清少侠、敌人、内力、危险 |
| 动画 | 移动、攻击、受伤、死亡、拾取、领悟、头目预兆 | 动作变化不只靠数值和文字 |
| 特效 | 命中、击杀、内力吸附、领悟、进阶、受伤、头目技能 | 0.2 秒内能看出关键事件发生 |
| 声音 | 命中、击杀、拾取、领悟、受伤、头目预警、按钮反馈 | 关键事件有声音，且可调音量/静音 |
| HUD | 血量、等级、内力、时间、击杀、招式、头目血条 | 不遮挡少侠和危险范围 |
| 暂停/页面 | 主菜单、暂停页、设置、领悟选择、阵亡过渡、战后清点、翻阅秘籍结果 | 可暂停、重开、回菜单、调声音，死亡和翻阅流程清楚 |
| 关卡 | 1 个 MVP 关卡：青石山道 | 连续移动不会撞到可见硬墙、黑屏或刷怪断层 |
| 结算 | 胜利、失败、击杀、等级、铜钱 | 战后清点后可重开 |
| 铜钱系统 | 铜钱只由游玩结算产生 | 无充值、无广告、无每日压力 |
| 局外成长 | 3 个永久成长项 | 使用游玩铜钱解锁 |
| 铜钱抽秘籍 | 1 个基础秘籍池，消耗铜钱 | 概率公开，重复有补偿 |
| 存档 | `localStorage` | 刷新后保留局外成长和最好成绩 |

内力、等级、领悟三选一和招式进阶触发的实现级规则见 [14 Inner Power And Insight System](14-inner-power-and-insight-system.md)。江湖敌人、怪潮时间轴、精英和刷怪预算见 [17 Enemy Wave And Director System](17-enemy-wave-and-director-system.md)。

## 不做内容

| 内容 | 原因 |
| --- | --- |
| 商城/充值/广告 | 个人项目，不需要商业化 |
| 付费抽卡/付费装备稀有度 | 会把目标带偏到数值诱导 |
| 大量角色 | MVP 先验证核心手感 |
| 多关卡 | 先把 `青石山道` 1 个关卡做扎实 |
| 联机 | 成本高，和核心爽感无关 |
| 账号系统 | 本地朋友试玩不需要 |
| 复杂剧情 | survivor-like MVP 不靠剧情成立 |

## 第一版招式池

实现级规则见 [16 Skill And Advancement System](16-skill-and-advancement-system.md)。

| 招式 | 基础行为 | 进阶方向 |
| --- | --- | --- |
| 游龙剑气 | 自动瞄准最近敌人发出剑气 | 穿透、连发、追踪 |
| 回风飞镖 | 飞镖围绕少侠旋转，近身防护 | 更大半径和更多飞镖 |
| 震山掌 | 定时释放近身冲击波 | 更大范围和短冷却 |

MVP 必做前三个招式。`毒砂袖箭` 和 `护体真气` 留到 MVP 成功后的扩展。

实现级规则见 [17 Enemy Wave And Director System](17-enemy-wave-and-director-system.md)。

| 敌人 | 优先级 | 行为 | 用途 |

## 首关头目 MVP

首关头目暂定为 `黑风寨主`，MVP 固定在第 6 分钟触发入场请求，不做击杀数提前触发。

头目行为：

- 冲撞斩：锁定少侠方向后短暂停顿，再直线冲刺。
- 旋风刀：原地蓄力后环形刀气扩散，逼少侠走位。

头目验收：

- 用户能看出攻击预兆。
- 头目不靠突然秒杀制造难度。
- 击败头目后出现战后清点。

## 局外成长边界

允许：

- 最大生命 +5%。
- 移动速度 +3%。
- 初始拾取半径 +5%。

限制：

- 每项 MVP 最多 5 级。
- 局外成长成本只来自局内铜钱。
- 不允许付费跳过。
- 不允许每日登录压力。

## 铜钱系统

MVP 新增铜钱只来自单局结算，不允许购买。翻阅秘籍重复奖励可以返还少量铜钱，但不作为战斗掉落来源。

MVP 建议公式：

```text
铜钱 = floor(存活秒数 / 10) + 击杀数 * 1 + 等级 * 8 + 头目奖励
```

| 情况 | 目标收益 |
| --- | ---: |
| 早期失败，约 2 到 3 分钟 | 60 到 120 铜钱 |
| 中段失败，约 4 到 5 分钟 | 150 到 260 铜钱 |
| 击败头目 | 350 到 500 铜钱 |

单抽成本建议 `300` 铜钱。目标是 3 到 5 局早期失败也能抽一次，完整胜利约能抽一次以上，但不会每局大量抽到失去稀缺感。

## 铜钱抽秘籍边界

抽秘籍允许，但只能作为局外收藏和轻成长系统。

MVP 抽取池建议：

| 奖励类型 | 概率 | 说明 |
| --- | ---: | --- |
| 普通残页/铜钱返还 | 65% | 用于兑换服饰或轻成长材料 |
| 稀有外观残页 | 25% | 不影响战斗或只影响视觉 |
| 稀有心法碎片 | 9% | 满碎片后解锁小幅局外加成 |
| 史诗收藏品 | 1% | 主要是称号、招式皮肤或特效 |

限制：

- 概率必须在抽秘籍界面明示。
- 重复奖励必须转为残页或铜钱返还，不能完全作废。
- 每 `20` 抽至少获得 1 个稀有或以上奖励。
- 不做限时池，不做付费池，不做保底付费加速。
- 抽秘籍相关战力加成在 MVP 中最多贡献长期战力的约 `15%`，不能成为通关必需。

## 美术、动画和特效边界

详细规格见 [10 Art Animation VFX](10-art-animation-vfx.md) 和 [12 Wuxia Style And Level](12-wuxia-style-and-level.md)。

MVP 不要求商业最终美术，但必须有完整的 P0 视觉反馈：

- 少侠、敌人、内力光点、铜钱、头目、剑气/暗器和危险刀痕必须一眼能分清。
- 自动招式、命中、死亡、拾取、领悟、进阶、受伤和头目预兆必须有动画或特效。
- 禁止用纯文字解释核心反馈，例如“你领悟了”“敌人受伤了”不能替代视觉反馈。
- 临时资产可以简单，但不能全是同色圆形、同色方块或无法区分的占位图。

## 声音、HUD 和暂停页面边界

详细规格见 [11 Audio HUD Pause](11-audio-hud-pause.md)。

MVP 必须满足：

- 战斗关键事件至少有短音效：命中、击杀、拾取、领悟、受伤、头目预警。
- 必须有全局静音、音乐音量、音效音量。
- HUD 只显示战斗中必须信息，不能把移动端玩法区域挤没。
- 暂停页必须能继续、重开、回主菜单、打开设置。
- 暂停时战斗逻辑必须停止，不能后台继续掉血。
