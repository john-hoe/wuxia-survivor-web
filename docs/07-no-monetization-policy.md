# 07 No Monetization Policy

## 目的

本项目是个人和朋友一起玩的 Web 小游戏，不面向商业发行。因此不需要，也不允许设计任何显性或隐性收费内容。

## 禁止内容

| 内容 | 状态 |
| --- | --- |
| 商城 | 禁止 |
| 充值货币 | 禁止 |
| 付费抽卡 | 禁止 |
| 付费角色 | 禁止 |
| 付费皮肤 | 禁止 |
| 战令 | 禁止 |
| 体力系统 | 禁止 |
| 广告复活 | 禁止 |
| 广告双倍奖励 | 禁止 |
| 限时礼包 | 禁止 |
| 每日登录压力 | 禁止 |
| 付费加速成长 | 禁止 |

## 允许内容

| 内容 | 条件 |
| --- | --- |
| 局外永久成长 | 只能用局内铜钱 |
| 铜钱抽秘籍 | 只能消耗游玩获得的铜钱，概率公开，重复有补偿 |
| 皮肤 | 只能通过成就、击败头目或本地挑战解锁 |
| 新角色 | 只能通过游玩解锁 |
| 本地排行榜 | 不上传个人数据 |
| 每日种子 | 只用于固定挑战，不绑定奖励压力 |

## 判断标准

一个设计如果满足任一条，就不适合本项目：

- 让用户为了更强而付费。
- 让用户为了省时间而付费。
- 让用户为了复活而看广告。
- 让用户因为错过每日奖励产生压力。
- 把正常游玩体验故意拆碎，再卖回给用户。
- 把铜钱抽秘籍做成需要充值、广告或每日任务压力才能有效使用。

## 局外成长原则

详细铜钱、局外成长、翻阅秘籍和存档规则见 [20 Copper Meta Scripture System](20-copper-meta-scripture-system.md)。

局外成长的作用是让失败有轻微积累，不是制造付费需求。

量化边界：

- 单项永久成长最高 5 级。
- 总局外加成不应让第一分钟难度完全失效。
- 局外成长只提供 10% 到 30% 的长期优势，主要爽感仍来自局内构筑。
- 抽秘籍来源的长期战力加成在 MVP 中不超过约 15%。

## 铜钱抽秘籍规则

铜钱抽秘籍允许存在，但它必须是“游玩奖励消耗口”，不是商业化入口。

必须满足：

- 铜钱只能来自单局结算。
- 不能购买铜钱。
- 不能看广告换铜钱。
- 概率必须明示。
- 重复奖励必须转为残页或铜钱返还。
- 每 20 抽至少保底 1 个稀有或以上奖励。
- 不做限时池和错过压力。
- 不做付费保底、付费十连、付费礼包。

## 决策规则

如果未来有朋友建议“加个商城/广告/付费抽卡会不会更像原作”，默认回答：

> 不加。我们要的是 survivor-like 的爽感循环，不要商业化压力。

## 边界案例

| 设计 | 判定 | 原因 |
| --- | --- | --- |
| 击败头目给铜钱 | 允许 | 来自游玩 |
| 失败也给少量铜钱 | 允许 | 保留进度，不付费 |
| 铜钱抽秘籍 | 允许 | 只消耗游玩铜钱，概率公开 |
| 付费买铜钱 | 禁止 | 直接商业化 |
| 看广告双倍铜钱 | 禁止 | 广告压力 |
| 每日登录送抽取 | 禁止 | 日常压力 |
| 限时秘籍池 | 禁止 | 错过压力 |
| 皮肤通过成就解锁 | 允许 | 不收费 |
| 皮肤付费购买 | 禁止 | 付费内容 |
