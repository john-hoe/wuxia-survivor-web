# 37 · 市场调研与视觉升级方案（2026-07-27）

> 调研范围：海外头部（Vampire Survivors / Halls of Torment / Soulstone / DRG:S / 20MTD / Nordic Ashes / Death Must Die）、亚洲与武侠同类（弹壳特攻队 / 弓箭传说 / 通神榜 / 暖雪 / 行侠仗义五千年）、Phaser 3.90 渲染技术可行性、国风 2D 标杆（鬼谷八荒 / 太吾绘卷 / 暖雪 / 墨斗 / 斩妖行 / 了不起的修仙模拟器）。
> 游戏现状：打击感/抽卡演出/极简 UI/BGM 音效/氛围三层已完成；已知短板=地图偏静态、技能特效少、局外成长表现一般。

## 市场结论（五条共性规律）

1. **反馈密度 > 特效精度**：弓箭传说场景美术低成本，靠击退分级/受击形变/数字配色就做出强手感；弹壳靠数量规模。爽感是系统工程，不是美术质量。
2. **单图多面貌是标配**：VS 的天气关（Whiteout 暴风雪）、移动背景、DRG 的"黑暗视野"难度修饰——用光照/天气让一张图有多张脸。
3. **危险色必须统一**：Jotunnslayer 用粒子颜色区分威胁；20MTD 用双色调。满屏弹幕时"一眼辨威胁"是底线。
4. **meta 界面主题化**：Soulstone 技能树、Nordic 世界树、通神榜"第二套立绘"——局外成长视觉化 = 长期留存锚点。
5. **统一渲染管线 > 单件精美**：修仙模拟器"人物和背景不搭调"是最大差评点；通神榜 5 人团队靠统一描边宽度/调色板/光源方向保统一。

## 方案一 · 竹雨听风（氛围跃升包）⭐ 推荐首选

> 直击"地图偏静态"，全部低成本。

| 项 | 内容 | 成本 | 来源启发 |
|---|---|---|---|
| 天气三层 | 雨/雪/落叶粒子分层 + 滚动雾贴图（scrollFactor 分层，emitter 注意 restart 销毁） | 低-中 | VS Whiteout、Phaser 粒子指南 |
| 色温叙事 | 相机级 ColorMatrix 渐变：常规青绿冷调 → 精英/Boss 波压暗泛朱砂 → 击杀回落 | 低 | 暖雪色温、DRG 黑暗修饰 |
| 移动背景 | 幡旗飘动、竹叶摆动、远处云影/水面流动感 | 低 | VS 移动背景 |
| 动态暗角 | 相机 Vignette 常驻，低血/Boss 战收紧 | 低 | Phaser FX 文档 |

## 方案二 · 剑意墨韵（技能视觉语言包）

> 建立"武侠特效语义"，为后续新技能铺路。

| 项 | 内容 | 成本 |
|---|---|---|
| 水墨笔触贴图 | 4-6 张溅墨/晕染/飞白贴图，替换部分通用粒子（AI 生成管线已通） | 中 |
| 配色语义 | 青白=剑气、金红=掌风内功、紫黑=邪毒；玩家看色即懂属性 | 低 |
| 技能形态进化 | 3 个技能 × 等级做视觉分级：数量/拖尾厚度/色温变化，3 技能做出 9 级差异 | 中 |
| 关键帧聚焦 | 只在破招/斩杀/进化瞬间给满特效+顿帧，平时克制 | 低 |
| 进化瞬间包装 | 短 hit stop + 全屏墨晕扩散 + 技能图标换底 | 中 |

## 方案三 · 经脉武学（局外成长主题化包）

> 治"局外成长表现一般"，题材契合度极高。

| 项 | 内容 | 成本 |
|---|---|---|
| 经脉成长树 | 局外成长改成"门派经脉图/武功谱"，节点即穴位，连线即经络 | 中 |
| 境界突破视觉化 | 突破解锁第二套立绘/称号印章（通神榜"通神"） | 中 |
| 抽卡器物承载 | 结果以卷轴/签筒展开呈现；稀有度递进揭示动画（卡面依次升色） | 中 |
| 图鉴线索底色 | 未收集项底色暗示，引导收集欲 | 低 |

## 方案四 · 夜雨灯明（渲染技术试点包）

> 挑着做的技术亮点，不建议全上。

| 项 | 内容 | 成本 | 备注 |
|---|---|---|---|
| Light2D 试点 | 灯笼/主角/剑光 ≤5 光源，Laigter 出法线图 | 高 | 120 敌全员打光不可行，只试点 |
| 短时 Glow | Boss 登场蓄力/受击边缘光，对象级 postFX 短时开关 | 中 | 相机级 FX 才可常驻 |
| 墨晕溶解转场 | 自定义 PostFXPipeline（噪声图+阈值），Boss 登场/结算转场 | 中 | 强风格化记忆点 |
| 预烘焙描边 | 敌群描边美术预烘焙（零运行时成本） | 低 | 高密度混战可读性 |

## 方案五 · 战场秩序（可读性与反馈密度包）

> 低成本高密度反馈，弓箭传说公式。

| 项 | 内容 | 成本 |
|---|---|---|
| 击退分级 | 小怪大幅击退、精英原地抖动、Boss 不动 | 低 |
| 数字分层 | 暴击放大弹跳、属性配色、稀有掉落金字 | 低 |
| 屏幕压暗聚焦 | 受击/Boss 出场瞬间压暗全场只留技能高亮 | 低 |
| 特效分级开关 | 设置里飘字/震屏/特效逐项开关（DRG:S/VS 无障碍惯例） | 低 |
| 敌人描边统一 | 统一描边宽度+同调色板 tint（渲染管线统一收尾） | 低 |

## 建议路线

1. **方案一 + 方案五**（1 周内）：地图活起来 + 反馈密度翻倍，直击当前最大短板
2. **方案二**（随第 4 个技能落地）：建立技能视觉语言地基
3. **方案三**（中期版本）：局外成长主题化，留存向
4. **方案四**：只做"墨晕溶解转场 + 短时 Glow"两项，Light2D 暂缓
